# Milo — Shih Tzu Puppy Portfolio

## Files
- `index.html` — Home, About, Contact sections
- `blog.html` — Separate blog-only page
- `style.css` — Complete responsive styling
- `script.js` — Navigation, form placeholder, dynamic year and blog interactions

## Run
Open `index.html` in a browser. No backend is required.

## Bootstrap
Bootstrap 5.3.3 is loaded from jsDelivr CDN.

## Notes
- The contact form is front-end only for now.
- Blog article links are placeholders for future backend/CMS integration.
- Images currently use remote Unsplash URLs. Replace them with your own puppy images when deploying if desired.
